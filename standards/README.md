## Separate project-creation process

`Projects all 16 creation` contains the upstream process for creating a grade's 16 projects. It is outside the curriculum workflow. Once the completed project set is handed off, do not load that folder's instructions, draft inventories, audits or intermediate designs during curriculum planning. Reopen project creation only when the user explicitly requests it.

Only the completed project handoff crosses this boundary. Do not substitute an old draft inventory for that handoff or assume a historical proposal is approved.
