# Curriculum Brain Instructions

Create and refine one step-by-step guide for building a curriculum from standards. During this phase, improve the guide without changing existing curriculum materials.

**Process boundary:** Curriculum building begins with the completed grade set of 16 projects. Creating/selecting those projects is a separate process in `Projects all 16 creation`. Once that set is handed off, do not read or apply that folder's instructions, draft inventories, audits or intermediate designs during curriculum work. Use only the completed project handoff, official standards and current curriculum files. Reopen project creation only at the user's explicit request. Keep the final handoff in the grade folder when supplied; do not require curriculum work to navigate the creation folder.

1. **Read first.** Review the current guide and agreed decisions before editing.
2. **Build together.** Define the process from standards to learning objectives, scope and sequence, lessons, and assessments. Ask when a decision is needed; make routine edits directly.
3. **Make steps usable.** State what each step needs, what to do, and what it produces.
4. **Test and refine.** Walk through a small example to find gaps, confusion, and unnecessary work.
5. **Maintain one guide.** Keep the curriculum-building process in [CURRICULUM_STEP_GUIDE.md](CURRICULUM_STEP_GUIDE.md), separate from these brain instructions and the project-creation process. Apply every agreed improvement directly there, never in a supplement or linked correction.
6. **Replace and simplify.** Keep only the latest complete guide. Rewrite before adding rules; remove outdated text and repetition. Use the fewest clear words without losing necessary instructions.
7. **Verify.** Check that the steps are complete, consistent, and usable. Keep change summaries and revision discussions in chat, not in the guide.
