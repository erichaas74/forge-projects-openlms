# Template D — Workshop & Defend

**Use for:** the individual lesson that closes gaps and finishes the student's own part of the final product. In math: **W4-I** of every project.

**What students experience:** a quick diagnostic sends them to the workshop they need, they revise their part of the final product and write a recommendation with a scaffold, then answer a fresh transfer task.

Shared settings are in the [README](README.md#part-3--settings-used-by-every-template). This template depends on routing, so set up either the PLD rules or the restrictions below before copying it.

## Build steps

Create a subsection named `Template D — Workshop & Defend`, then add these items in order.

### Routing (pick one)
- **Simple restrictions:** give each item in *Where am I?* its own question category, and restrict workshop 1 by **Grade → `[ID] ① Where am I?` → must be < [threshold]**. If one quiz can't separate topics, make one tiny quiz per topic (`① Where am I? Ratios`, `① Where am I? Fractions`) and restrict each workshop on its own quiz.
- **PLD (recommended here):** one rule per topic quiz: *grade < threshold* → *add user to group "Workshop: [topic]"*. Restrict each workshop by that group. Add a rule for the previous lessons' rechecks too, so students still flagged from Weeks 1–3 land in the right group automatically.
- Teachers can also add a student to a workshop group by hand from Participants → Groups, based on the evidence record the guide describes.

## Worked example: M1-W4-I — Finish and defend an individual recommendation

| # | Item | What goes in it |
| --- | --- | --- |
| 1 | ① Where am I? | Ratio item (compare two offers in a table) and fraction-division item (interpret a quotient). Also reopen any percent, speed, conversion or algorithm items flagged earlier. |
| 2 | ② Workshop: ratio representation | Model on different numbers; link table, equation and graph point. |
| 3 | ② Workshop: fraction model | (5/6) ÷ (1/3) = 5/2 with strips and an inverse check. |
| 4 | ② Improve your explanation | "Show how a recommendation cites quantity, cost and a reason to reject the other offer." |
| 5 | ③ Write your recommendation | Structure Strip: *My recommendation* · *The numbers that prove it* · *Why not the other supplier* · *How I checked it's enough*. 4–6 sentences total. |
| 6 | ③ Final individual file | 1. Audit your file against the product criteria. 2. Attach the recommendation to the final table. 3. Revise one weak representation. Rubric: feasibility justified; choice uses the student's own calculations; representations linked. |
| 7 | ④ Transfer check | Calculated: 3 tickets for $2.40 versus 5 for $4.25 → cost of 15 tickets ($12 versus $12.75), with variants. Essay with drawing upload: interpret (3/4) ÷ (2/3) = 9/8 with a model and inverse check. Link 6.RP.A.3, 6.NS.A.1. |
| 8 | ⑤ Still to work on | "Anything not yet secure gets one more check in the supply exchange and carries into M2." |

## Before students see it
- [ ] Routing tested with three test students: one needing topic 1, one needing topic 2, one needing neither.
- [ ] Every student sees at least one ② item (no empty slot).
- [ ] Diagnostic quiz in Practice; final file and transfer check in Individual evidence.
- [ ] Rubric uses descriptive levels from *How the work is judged*; no invented cutoffs.
- [ ] Structure Strip tested on a phone or tablet if students use them.
- [ ] Competencies linked.
