# Standards reference library

Downloaded October 2, 2026 for Grades 4–6 curriculum planning. The selected Tennessee baseline is the **2027–28 school year**, as requested. Original publisher PDFs are preserved in full so grade-level standards retain their introductions, practices, and progression context.

## Tennessee baseline for 2027–28

| Subject | Local document | Edition and use |
| --- | --- | --- |
| ELA | [Tennessee ELA](TN_ELA_2019_K-12.pdf) | Current ELA document linked by TDOE, February 2019 attachment. Grades 4–6 appear in vertical strand tables. The newly revised ELA standards target 2029–30, so they are not the selected 2027–28 baseline. |
| Mathematics | [Tennessee mathematics](TN_Math_2021_K-12.pdf) | Revised October 2021; implemented in 2023–24. Includes Grades 4, 5, and 6 and the mathematical practice and literacy expectations. |
| Science | [Tennessee science](TN_Science_2022_K-12.pdf) | Adopted October 2022; implemented in 2025–26. Includes Grades 4, 5, and 6. |
| Social studies | [Tennessee social studies for 2027–28](TN_Social_Studies_2027-28_K-12.pdf) | Revised standards adopted in 2024, linked by TDOE for implementation in 2027–28. Use this document for new planning. |

An [earlier social studies document](TN_Social_Studies_Pre-2027_K-12_REFERENCE_ONLY.pdf) is retained only to interpret older project assignments and crosswalks. It is not the selected baseline.

The existing Forge CSVs and project assignments have not been revalidated against this library. In particular, check social studies assignments against the 2027–28 standards before claiming alignment. Downloading the source documents does not update the existing crosswalk automatically.

## National reference standards

| Reference | Local document | Scope |
| --- | --- | --- |
| Common Core ELA and literacy | [Common Core ELA](Common_Core_ELA_Literacy_K-12.pdf) | Full K–12 standards, including Grades 4–6 and literacy in history/social studies, science, and technical subjects. |
| NGSS | [NGSS arranged by disciplinary core idea](NGSS_All_Grades_DCI.pdf) | Full standards with performance expectations, practices, core ideas, and crosscutting concepts. Use Grade 4, Grade 5, Grades 3–5 engineering design, and the middle-school Grades 6–8 band. NGSS does not provide a separate universal Grade 6 allocation. |
| NSQ Online Courses | [2025 courses standards](NSQ_Online_Courses_2025.pdf) | Course-design reference for curriculum work. |
| NSQ Online Teaching | [2025 teaching standards](NSQ_Online_Teaching_2025.pdf) | Teaching-quality reference. |
| NSQ Online Programs | [2025 program standards](NSQ_Online_Programs_2025.pdf) | Program-quality reference; official publication copy hosted by Ohio's education department. |
| NSQ Digital Learning Leadership | [Saved official webpage](NSQ_Digital_Learning_Leadership.html) | Additional NSQ standards set saved as HTML, not PDF. Text is stored locally; styling and images may require internet access. |

NSQ standards describe educational quality, not additional student subject-content standards. Keep national references distinct from the selected Tennessee baseline.
